# Contributing to DermaScan

Thank you for your interest in contributing to **DermaScan**! We welcome contributions from developers, data scientists, and healthcare AI researchers.

---

## 📜 Code of Conduct

Please review and adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions and contributions.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
If you encounter a bug or unexpected behavior:
1. Search existing issues to ensure it hasn't been reported.
2. Open a new issue with a clear title, description, steps to reproduce, and environment details.

### 2. Suggesting Features
Enhancement suggestions are welcome! Please open an issue outlining:
- The problem your feature solves.
- Proposed implementation details or workflow.
- Potential impact on model performance or system architecture.

### 3. Submitting Pull Requests
1. **Fork the Repository**: Create your feature branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Set Up Local Environment**: Follow the setup instructions in the root [README.md](README.md).
3. **Commit Changes**: Use descriptive, atomic commit messages:
   ```bash
   git commit -m "feat(backend): add image validation error handling"
   ```
4. **Push & Create PR**: Push your branch to your fork and submit a Pull Request targeting `main`.

---

## 📏 Code Style Guidelines

- **Python (Backend)**: Adhere to PEP 8. Use standard docstrings for function definitions.
- **JavaScript/React (Frontend)**: Follow standard ES6+ conventions and component modularity.
- **Documentation**: Ensure any code or model updates are reflected in directory README files.
